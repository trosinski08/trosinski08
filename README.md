## 🔬 Featured Projects

**🤖 [AI Agent Compliance](https://github.com/trosinski08/ai_agent_compliance)**
Local RAG system for AML/KYC case analysis — Ollama, Qdrant, sentence-transformers, FastAPI, Streamlit. Indexes Polish AML legislation (Ustawa AML 2018, GIIF guidelines, KNF recommendations), retrieves relevant articles, and returns cited decisions. Everything runs locally — no data leaves the machine.
**Stack:** Python · Ollama · Qdrant · FastAPI · Streamlit

**📈 [Autonomous AI Investment Agent](https://github.com/trosinski08/Invest_AP)**
Trading agent powered by GPT-4o-mini with a Streamlit monitoring dashboard. Structured decision validation via Pydantic v2, circuit-breaker guardrails (max loss, max trades, cooldown), unit tests. Deployed to AWS Elastic Beanstalk (Web + Worker tier).
**Stack:** Python · OpenAI API · Binance API · Pydantic v2 · AWS

**🎯 [SureBetHunter](https://github.com/trosinski08/SureBetHunter)**
FastAPI service detecting arbitrage opportunities across bookmakers, with Google Sheets integration for tracking. Pydantic v2 validation for OddsAPI responses, deployed to AWS Elastic Beanstalk.
**Stack:** Python · FastAPI · Pydantic v2 · gspread · AWS

**🛡️ [PPE Safety Detection](https://github.com/trosinski08/ohs-detection)**
Real-time PPE/workplace safety detection using YOLOv10. Modular, class-based architecture with configurable pipelines, model export (ONNX/TorchScript/TFLite/CoreML), unit tests.
**Stack:** Python · YOLOv10 · OpenCV · Docker

**🚁 [Drone Intelligence Reports](https://github.com/trosinski08/pdf_report_generator)**
Automated PDF report generation from drone video for a client (AltaAres) — extracts KLV telemetry (GPS, timestamps), runs YOLOv10 object detection per frame, matches detections to GPS coordinates, and renders multi-page PDF reports with maps and detection timelines.
**Stack:** Python · YOLOv10 · ffmpeg · Folium

**🏪 [Loopstore](https://github.com/trosinski08/loopstore)**
Full-stack e-commerce platform for upcycled clothing. Next.js/React frontend, Django REST Framework backend, PostgreSQL, Docker.
**Stack:** Next.js · Django · PostgreSQL · Docker

**🏓 [ft_transcendence](https://github.com/trosinski08/ft_transcendence_42)**
Real-time multiplayer Pong SPA, built as a 42 School team project. Vanilla TypeScript, WebSocket game engine, AI opponent, ELK Stack log aggregation, Docker + nginx with HTTPS and strict CSP headers.
**Stack:** TypeScript · Prisma · ELK Stack · Docker · nginx

**💰 [Customer Lifetime Value Predictor](https://github.com/trosinski08/CLV_preditor)**
